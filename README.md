# Marry Mate V2

> 둘이 함께 비교하고 결정하는 결혼 준비 공간

Marry Mate V2는 준비 항목, 후보 업체, 체크리스트, 견적, 계약, 결제 일정과 실제 사용 금액을 Couple Workspace에서 함께 관리하는 서비스입니다.

## 현재 구현 단계

- 새 V2 프로젝트 기반
- Spring Boot 4, Java 21, MySQL, Flyway
- React 19, TypeScript, Vite
- 이메일·비밀번호 회원가입과 로그인
- Couple Workspace, 초대 코드와 멤버십 권한 검사
- 공유 목표 예산과 계약금·중도금·잔금 저장
- 결제 예정일과 결제 완료 처리
- 웨딩홀·플래너·촬영·스튜디오·본식 준비 체크리스트 20종
- 업체 후보별 견적·실사용액·평점·장단점 비교
- 암행투어·실제 상담·하객 투어 후기 기록
- 준비 일정과 결제 예정일을 합친 월간 캘린더
- 모바일 우선 공동 준비 대시보드
- 모든 화면에 예식일 D-day 표시 및 캘린더 자동 반영
- 원 단위 금액 입력과 천 단위 쉼표 표시
- 준비·업체 비교 견적의 예산노트 자동 연동 (미확정은 항목별 최저 견적)
- 패키지 포함 항목의 총액·계약 결제 공유와 중복 합산 방지
- 계약별 계약금·중도금·잔금 일정 수정 및 실제 납입일 표시
- 웨딩홀 1인 식대·보증인원·대관료 저장 및 계약금·중도금을 뺀 잔금 계산
- 신혼여행 포함 여부·예상 축의금 차감 설정
- 공유 공간의 메인 제목·소개 문구 설정
- 일반 항목·패키지 포함 항목의 추가금과 결제 예정일 자동 연동
- 준비 체크·업체 비교·패키지·예산·결제 목록의 금액·날짜·결제자 정렬
- 준비 체크에서 계약금·중도금·잔금 관리 (예산·캘린더와 같은 기록 사용)
- 예정·완료 결제 내역을 한 목록에서 확인
- 준비 체크 카테고리별 정렬·카테고리 순서 변경 (브라우저에 사용자·공간별 저장)
- 준비·완료 항목을 카테고리별 한 목록에 표시
- 가입 후 새 스페이스 만들기 또는 초대코드로 참여
- 예정·미납 결제는 예정자 또는 미정 선택, 납입 완료 시 실제 결제자 확인
- 상견례 식사·선물은 준비 체크와 업체 비교에서 관리
- 청모 전용 탭에서 모임명·장소·날짜·시간·비용과 참석 인원·이름·신부 측/신랑 측/공통 구분 저장
- 청모 날짜와 시간이 캘린더에 자동 반영되고 참석자 기록을 공유 공간에서 함께 관리
- 메뉴 설정에서 내비게이션 보이기·숨기기와 순서 변경, 계정별 서버 저장으로 다른 기기에서도 유지
- 저장·변경 알림은 5초 후 자동 닫힘
- 결제자 그래프는 실제 납부액만 집계하고 부분 납부·환불·완료 항목의 납부 이력 반영
- 카테고리·결제자 그래프의 호버·터치·키보드 상세 결제 명세
- 신혼여행 비용과 예상 축의금 수입을 동일한 포함/제외 방식으로 선택·즉시 저장 (포함한 축의금 수입은 부담액에서 차감)
- 예산 표·카테고리 그래프에 같은 견적 합계와 축의금 차감 후 부담액 표시
- 결제 일정 없는 신혼여행 견적도 포함 옵션에 따라 예산에 반영
- 웨딩홀 계약금·중도금·잔금과 예상 축의금을 함께 입력하며 예산 탭과 축의금 공유
- 웨딩홀 계약금·중도금·잔금은 직접 입력하고, 축의금만 보증인원 × 1인 식대로 자동 계산
- 웨딩홀 납입 합계가 기존·식대 기준 총액과 다르면 확인 후 입력한 총액을 예산·그래프에 반영
- 프로필 메뉴에서 내 메뉴 표시·순서 설정
- 홈 꾸미기에서 카드 표시·순서와 캘린더 이번 주·한 달 선택 (브라우저에 계정·공간별 저장)
- CATEGORY 그래프에 축의금 포함·제외 직접 반영, 포함 시 웨딩홀 비용에서 차감

기존 프로토타입은 `feature/backend-rebuild` 브랜치의 `cf286f6` 커밋에 보존되어 있습니다.

## 로컬 실행

환경 파일을 준비합니다.

```bash
cp .env.example .env
```

MySQL을 실행합니다.

```bash
docker compose up -d mysql
docker compose ps
```

백엔드를 실행합니다.

```bash
cd backend
./gradlew bootRun
```

프론트를 실행합니다.

```bash
cd frontend
corepack pnpm install
corepack pnpm dev
```

기본 주소:

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:8080`
- Health: `http://localhost:8080/actuator/health`

## 현재 공개 테스트 주소

- Frontend: `https://marry-mate-together.koy4648.chatgpt.site`
- API: Cloudflare Quick Tunnel 사용

지인에게 Frontend 링크를 공유하면 회원가입 후 각자의 준비 공간에서 테스트할 수 있습니다. 기존 공간을 함께 사용하려면 초대 코드로 참가합니다. 화면은 Sites에, API와 MySQL DB는 이 Mac의 Docker에 배포되어 있으며 별도 관리자 웹 화면은 아직 없습니다.

Quick Tunnel은 계정 없이 사용하는 임시 연결입니다. Mac mini와 아래 컨테이너가 계속 실행되어야 하며, Tunnel 컨테이너를 새로 만들면 API 주소가 변경될 수 있습니다.

```bash
docker compose --profile quick-tunnel up -d mysql api quick-tunnel
docker compose ps
docker compose logs --tail=50 quick-tunnel
```

정식 운영 시에는 Cloudflare 계정의 Named Tunnel 또는 별도 호스팅 서비스로 전환합니다.
