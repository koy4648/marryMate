# Wedget

Wedding + Budget

결혼 준비 과정에서 발생하는
예산, 견적, 계약, 결제, 청첩장 모임 등을 관리하기 위한
웨딩 플래닝 서비스.

## Tech Stack

Backend
- Java 17
- Spring Boot 3
- Spring Data JPA
- MySQL
- Gradle

Frontend
- React
- TypeScript
- Vite
- PWA

## Main Features

- 웨딩 전체 예산 관리
- 카테고리별 예산 관리
- 예상 비용 / 실제 지출 관리
- 결제 상태 및 결제자 관리
- 식대 별도 관리
- 청첩장 모임 관리
- 업체 및 견적 비교
