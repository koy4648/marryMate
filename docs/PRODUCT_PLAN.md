# Marry Mate V2 제품 범위

## 목표

두 사람이 결혼 준비 과정의 선택과 비용을 같은 데이터로 확인하고 결정할 수 있게 한다.

## 핵심 흐름

```text
커플 연결
→ 준비 항목 선택
→ 후보 업체 등록
→ 상담·방문 기록
→ 견적 비교
→ 계약
→ 계약금·중도금·잔금
→ 실제 사용 금액
→ 이용 후기
```

## MVP 준비 영역

- 웨딩홀: 암행투어, 실제 상담, 하객 경험
- 플래너
- 본식 촬영: 스냅·원판, DVD, 아이폰 스냅
- 스튜디오: 작가, 헬퍼, 헤어변형, 헤어·메이크업, 대여, 드레스, 예복
- 본식: 헬퍼, 헤어·메이크업, 드레스, 예복
- 혼주: 한복, 아버지 예복, 헤어·메이크업

## 예산 원칙

- 목표, 예상, 계약, 결제 완료, 잔여, 실제 금액을 구분한다.
- 계약금·중도금·잔금은 계약에 연결된 개별 결제로 저장한다.
- 예정일과 실제 결제일, 예정 금액과 실제 금액을 구분한다.
- 결제 상태는 예정, 일부 결제, 완료, 취소, 환불을 지원한다.
- 7일 이내 결제와 기한이 지난 결제를 대시보드에서 알린다.

## MVP 완료 기준

두 사용자가 본식 스냅 후보 세 곳의 상담과 견적을 기록하고 비교한 뒤 한 곳을 계약한다. 계약금·중도금·잔금의 예정일을 등록하고 결제 완료를 표시하면 예산과 다음 결제 일정이 자동으로 갱신되어야 한다.
